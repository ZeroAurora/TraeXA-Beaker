## Convex 前端接入计划

### 项目现状分析

* **项目类型**: React Router v7 + Convex 后端

* **已安装依赖**: `convex: ^1.31.2`

* **后端已有**: schema 定义、6个模块 (documents, chats, subscriptions, remix, vibe, dashboard)

* **环境配置**: `VITE_CONVEX_URL=http://127.0.0.1:3210`

### 实施步骤

#### 1. 创建 Convex 客户端配置

**文件**: `app/lib/convex-client.ts`

* 创建 `ConvexReactClient` 实例

* 导出客户端实例供全局使用

#### 2. 配置 Provider 包装应用

**文件**: `app/root.tsx`

* 导入 `ConvexProvider` 和客户端

* 在 `App` 组件外层包装 `ConvexProvider`

* 修复 import 路径使用生成的类型

#### 3. 创建 API 导出模块

**文件**: `app/lib/api.ts`

* 统一导出所有后端函数引用

* 简化组件中的 import 语法

优先执行前三步，然后暂停等待继续执行

#### 4. 更新前端组件使用 Convex

**文件**: `app/components/features/knowledge/knowledge-base.tsx`

* 使用 `useQuery` 替换 mock 数据获取

* 使用 `useMutation` 实现添加/删除文档

#### 5. 验证集成

* 运行 `npm run dev`

* 检查控制台无 Convex 连接错误

* 验证数据能正常加载和更新
