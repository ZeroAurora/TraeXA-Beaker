# Beaker烧杯 Mock UI 实现计划

## 整体布局结构

采用经典的三栏布局设计：

* **顶部导航栏 (Header)**: 包含Logo、搜索栏、用户设置按钮

* **左侧导航栏 (Sidebar)**: 包含功能菜单导航

* **主内容区域 (Main)**: 动态展示当前功能页面

* **右侧边栏 (Vibe Sidebar)**: 仅在特定页面显示Vibe Writing推荐内容

## 核心功能页面

1. **工作台 (Dashboard)**: 统计概览、最近活动、快捷操作
2. **内容抓取 (Crawler)**: URL输入、Jina Reader API集成、内容预览
3. **知识库 (Knowledge)**: 文档列表、搜索筛选、AI生成标记
4. **RSS订阅 (Subscription)**: 订阅源管理、自动导入状态
5. **智能聊天 (Chat)**: 对话界面、知识库引用、搜索结果
6. **知识重组 (Remix)**: 多文档选择、提示词输入、生成进度

## 目录结构

```
app/components/ui/           # shadcn/ui 基础组件
app/components/layout/      # 布局组件 (header, sidebar, vibe-sidebar)
app/components/features/    # 功能模块组件
app/routes/                 # 页面路由
app/hooks/                  # 状态管理钩子
app/data/                   # Mock数据
```

## 实现顺序

1. 安装shadcn/ui组件（使用shadcn MCP）
2. 创建布局组件
3. 实现工作台页面
4. 实现内容抓取页面
5. 实现知识库页面
6. 实现RSS订阅页面
7. 实现智能聊天页面
8. 实现知识重组页面
9. 配置路由

## 设计特点

* 蓝紫色调体现实验室/烧杯主题，以创意、实验为核心基调

* 知识重组功能是特色功能，要体现出优秀的页面设计

* 实时Vibe Writing推荐展示
