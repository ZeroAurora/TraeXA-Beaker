# Beaker Convex 后端实现计划

## 一、架构概览

### 1.1 技术选型

* **@convex-dev/rag**: 知识库RAG检索

* **@convex-dev/agent**: AI代理功能（Knowledge Remix）

* **OpenAI API**: 文本生成和嵌入

* **Jina Reader API**: 网页内容抓取

* **RSS Parser**: 订阅源解析

### 1.2 目录结构

```
convex/
├── schema.ts              # 数据库Schema定义
├── config.ts              # Convex组件配置
├── documents.ts           # 文档相关函数
├── crawler.ts             # 内容抓取（Web抓取+RSS）
├── rag.ts                 # RAG搜索功能
├── chat.ts                # Chat to Knowledge
├── remix.ts               # Knowledge Remix
├── vibe.ts                # Vibe Writing推荐
├── subscriptions.ts       # RSS订阅管理
└── crons.ts               # 定时任务
```

## 二、数据库Schema设计

### 2.1 核心表结构

* **documents**: 存储所有文档（抓取/AI生成）

* **subscriptions**: RSS订阅源

* **feed\_items**: 订阅条目

* **chat\_sessions**: 聊天会话

* **chat\_messages**: 聊天消息

* **remix\_tasks**: 知识重组任务

### 2.2 关键字段设计

* documents: source, url, title, content, isAIGenerated, embedding, metadata

* subscriptions: url, title, lastFetched, fetchInterval

* chat\_sessions: title, documentIds, createdAt

## 三、核心功能模块

### 3.1 内容抓取（Crawler）

* `crawlUrl`: 使用Jina Reader抓取网页内容

* `createSubscription`: 创建RSS订阅

* `syncSubscriptions`: 同步所有订阅

### 3.2 文档管理（Documents）

* `listDocuments`: 列出文档（支持分页、筛选）

* `getDocument`: 获取单个文档

* `deleteDocument`: 删除文档

* `searchDocuments`: 全文搜索

### 3.3 Chat to Knowledge

* `createChatSession`: 创建聊天会话

* `sendMessage`: 发送消息（RAG搜索+AI生成）

* `getChatHistory`: 获取聊天历史

### 3.4 Knowledge Remix

* `createRemixTask`: 创建重组任务

* `remixDocuments`: 使用Agent重组文档

* `getRemixResult`: 获取生成结果

### 3.5 Vibe Writing

* `getVibeRecommendations`: 基于内容推荐相关片段
