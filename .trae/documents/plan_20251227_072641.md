## Canvas-Centric 画布中心布局

### 核心设计理念

**内容优先，UI 作为覆盖层**
- 主内容区占满 100% 屏幕空间
- 所有导航和工具元素浮动在内容之上
- UI 元素精简到极致，仅保留必要交互

### 核心变化

#### 1. 全屏内容区（画布）
- 移除固定 Header、Sidebar、VibeSidebar 容器
- 主内容区域 `fixed inset-0 pt-0`
- 内容可滚动，UI 元素浮动在上方

#### 2. 悬浮搜索（右上角）
- 类似 Mac Spotlight 的搜索入口
- 点击或 Cmd+K 触发命令面板
- 搜索框平时隐藏，点击后展开

#### 3. 浮动导航球（右下角）
- 圆形悬浮按钮，带动画效果
- 点击展开导航菜单面板
- 支持快捷操作入口

#### 4. 上下文工具栏（顶部/左侧动态显示）
- 根据当前页面动态变化
- 如：Dashboard 显示欢迎语和操作按钮
- 聊天页面显示对话历史切换

#### 5. 极简用户信息
- 头像悬浮在搜索旁边
- 点击展开下拉菜单

### 组件层级关系

```
App
├── 全屏内容容器 (fixed inset-0)
│   ├── 页面内容层 (z-0, 可滚动)
│   │   ├── Header (浮动, 顶部)
│   │   ├── Sidebar (移除)
│   │   └── VibeSidebar (改为抽屉)
│   ├── 搜索覆盖层 (z-50)
│   ├── 导航面板 (z-40, 右下角触发)
│   └── 快捷操作浮层 (z-30)
```

## 实施计划

### 第一阶段：布局骨架重构

1. **重构 app/root.tsx**
   - 移除所有固定布局容器
   - 创建全屏画布容器 `fixed inset-0 overflow-hidden`
   - 主内容区使用 `h-screen w-screen overflow-auto`

2. **创建 FloatingHeader 组件**
   - 绝对定位在顶部
   - 精简为 Logo + 搜索 + 头像
   - 搜索框采用 Mac Spotlight 风格

3. **创建 FloatingNav 组件**
   - 悬浮球样式（右下角）
   - 包含导航菜单和快捷操作
   - 带平滑展开/收起动画

4. **重构 VibeSidebar**
   - 改为右侧抽屉式面板
   - 默认收起，点击触发
   - 支持滑动手势

### 第二阶段：页面内容适配

5. **重构 Dashboard 页面**
   - 移除传统 Card 边框
   - 采用更开放的空间布局
   - 统计卡片简化为数字大标签
   - 「最近活动」改为简洁列表

6. **重构各功能页面**
   - Chat 页面：极简对话界面
   - Remix 页面：专注编辑器
   - Knowledge 页面：文档列表优化
   - Crawler 页面：抓取任务面板
   - Subscription 页面：订阅源管理

### 第三阶段：交互优化

7. **命令面板 (Cmd+K)**
   - 全局快捷键触发
   - 搜索导航、功能命令、历史记录

8. **快捷操作菜单**
   - 右下角导航球内置
   - 快速访问核心功能

9. **转场动画**
   - 页面切换添加过渡效果
   - 导航展开/收起动画
